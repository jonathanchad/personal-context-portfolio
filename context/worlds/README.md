# Worlds — one life, four lenses

The files in this folder are **lenses on one life, not silos**. Jonathan's
day blends fluidly across parenting, school and the P&C, Charlotte,
clients and the tools. The old ten-file system divided that up too much
and he sunset it for exactly that reason. Don't recreate the division in
how you plan, brief or prioritise.

## How the worlds lean on each other

- A Charlotte crunch week is negotiated against Katie's travel and squad
  runs, not planned in a vacuum (`personal.md` ↔ `charlotte.md`).
- LAN's "proven techniques" are a pillar of the Charlotte pitch — the
  consulting wind-down and the new operation are the same story
  (`consulting.md` ↔ `charlotte.md`).
- The tools sell best inside client conversations, as an instrument
  offered mid-engagement, not as a separate sales motion
  (`breakthrough-tools.md` ↔ `consulting.md`).
- P&C work uses the same comms craft as client work; it just goes through
  the `pandc-compliance` skill first (`personal.md` ↔ the writer skills).

## Rules for agents

1. **Plan one day, not four.** A morning brief is a single timeline with
   school, P&C, Charlotte and client items prioritised together — never
   four sections that pretend the others don't exist.
2. **Carry constraints across.** A family commitment constrains a client
   call; a funder deadline constrains P&C time. Say so when they collide.
3. **Guardrails hold.** Squad, the anniversary, retainer caps, "never send
   email" — these are hard lines regardless of which world is loudest
   this week. See `personal.md` and `../preferences-and-constraints.md`.
4. **Surface the intersections.** If a decision in one world changes
   another (a hire that frees client time, a client ending that funds
   Charlotte time), name it rather than filing it under one heading.
